## Driver

A test-only RefCounted consumes current GameState and WorldAdapter plus the existing
static route. No authoritative mutation. At most one finite16-heading decision per
200ms supplied monotonic wall time. Headings are deterministic around the next source
route waypoint. Direct endpoint distance is min(70px,distance to waypoint); other
headings inspect70px. Every endpoint uses the actual detached player-body Adapter
sweep and contact/end verdict. Blocked/slid/inexact endpoints cannot be selected.
No full global route graph runs inside the driver. Existing one-time route setup
remains outside measurement.

Scores use route progress, current live hostile/cop distances to the actual
candidate segment and endpoint, and continuity with the prior chosen direction.
Threats are only currently live, visible contact peers with current hostile/aggro/cop
flags, within360px; no prediction from future state. Record their exact IDs/centers,
body sizes and flags. Source stats are not replaced by scoring weights.

The completed Office corner diagnostic proves that a long cast can miss a blocked
small-step endpoint in an unchanged margin band. Each otherwise eligible candidate
therefore also checks its first at most1 source pixel(.04m), from exact source
player x/y, with the real Adapter. Each rendered input frame freshly certifies both
the current-to-cached-endpoint segment and that short step. No whole-path sampling.
A changed revision, new peer obstruction,
stun, changed epoch or invalid result holds input. A changed revision clears the
endpoint but cannot reset the200ms decision allowance. This is at most16 candidate
sweeps plus16 short candidate sweeps and two retained sweeps on a decision frame,
and two on other frames. A rejected long candidate needs no short query.500ms of
requested movement with no observed progress invalidates the heading, excluding

No cadence catch-up loop after a long frame. Live movement remains production Input
and actual controller physics; a probe certificate never commits model position.

Use actual mouse motion events for view heading, plus normal WASD action strengths
encoded for Input.get_vector's circular deadzone. First click may capture the mouse

rotation directly. Sprint is an ordinary action only while a nearby active threat

escape urgent); it uses source speed/shakes/stun/damage. No artificial stamina or
speed rule. Otherwise release sprint. Hold on failure, with20s no actual progress
