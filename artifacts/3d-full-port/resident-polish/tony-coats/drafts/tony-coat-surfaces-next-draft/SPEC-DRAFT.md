silhouettes, coat openings, neck, cuffs, seams, bare torso, bone hierarchy, weights
algorithm, animation and counts remain. Lapels may move in front depth only;
choose an ordered separation from actual overlapping triangles, not their base
Z constants alone. Existing garment upper rings may change width/Y/front/back

if default inputs produce byte-identical output for all previous/default callers.
Only Tony's middle shell receives it. Preserve the original outer shell unless
actual finite coverage establishes a specific required upper-ring adjustment;

Static reconstruction may choose an initial candidate and limiting witnesses.
It is not posed acceptance. Keep any failed trial/result in this draft's report.

actual four-weight CPU deformation, with finite normals/bounds/caches intact.
