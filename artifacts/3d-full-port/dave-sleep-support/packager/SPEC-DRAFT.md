# Dave sleep support: retained evidence package

This specification precedes the copier. The packet audits and packages already
completed runs; it runs no engine, browser, export, Git command or production
mutation. Root alone may create the final artifact after reviewing the dry run.

Retain five distinct stages from `.build/full-port/dave-sleep-validation`:
`focused-v1`, `native-v1`, failed `web-v1`, `focused-driver-v2`, and `web-v2`.
Copy raw reports, original images, browser screenshots, logs, exit/provenance
records and exact art/driver/promotion specifications and overlays. Preserve
the historical false/pending fields in the original draft manifests. An audit
summary may describe later evidence separately; it cannot rewrite those fields
or upgrade the failed Web attempt.

Reference the existing 495-file archive at
`artifacts/3d-full-port/query-resource-rejected-v1/wrapper/source.zip`, SHA-256
`ede8f5bf42ed80f4227d3d1d17b69f89c30eab65722932557ed3334c26a46ee2`.
Verify its complete file inventory against all five staged source inventories,
and account for every changed/added staged path with its explicit overlay.
Do not copy that archive, an entire staged project, binaries, WASM/PCK exports,
generated caches, user data or unrelated experiments into this artifact.

The allowlist pins each copied source path, destination-relative path, length
and SHA-256. The copier reads bytes, verifies every input before creating output,
rejects path traversal, symlinks/reparse points and any existing destination,
then creates only `artifacts/3d-full-port/dave-sleep-support`. No deletion,
overwrite, EOL conversion, image re-encoding or JSON normalization of evidence.
Recheck each byte stream during copying and every destination hash afterward.
Write the package receipt last; an interrupted partial directory is retained
and may not be reused. Default verification creates no artifact.

Audit obligations:

- The exact same Animator `d35234cd...` is used by all stages. Only the declared
  driver/contract successor changes between Web v1 and v2; the old native run
  remains evidence for its original driver.
- Nine original PNGs must match their report hashes, byte sizes and 1280x720
  native / 960x540 Web framebuffer dimensions. Preserve both browser JPEGs and
  raw console JSON. Empty exported GDScript hashes are unavailable, not proof;
  staged source plus served/export hashes supply provenance.
- Native and Web v2 must have actual ordinary-input wake, unchanged immediate
  player/RNG receipt, four seconds of awake upright samples, pigeon dialogue,
  final playing movement above 0.15m and no failure/error entries. Web v1 must
  retain its exact final-route failure, absent movement and browser error text.
- Passive actual-ray measurements establish sampled ground clearance and the
  rigid head/pillow bounds. The focused triangle test establishes cushion
  contact across 384 samples, exact non-sleep restoration and unchanged other
  identities. Do not interpret helper `ok` as a continuous nonpenetration proof.
- Original-image review checks visible cushion support and awake pillow carry.
  The unchanged awake wrist attachment is a carry/restoration check, not new
  evidence for finger-pad grip, all hands, all animations or all surfaces.

Synthetic ordinary key/mouse events exercise production paths; they are not
trusted hardware input, pointer-lock, audio, performance, persistence, complete
gameplay or full-port acceptance. Packaging cannot establish any of those.
No existing parity status is changed. READY means the audited allowlist/copier
is held for root, not a committed or pushed completion report.
